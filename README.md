# Voice Valet

音声合成ソフトの「音声保存」を代行する AviUtl2 汎用プラグイン。
エディタ側の書き出し操作(メニュー・ダイアログ・ファイル名入力)をすべて自動化し、
ワンクリック(またはホットキー1発)でセリフの wav + txt を決まった場所に保存します。

## 主な機能

### 🎙 ワンボタンで音声保存

- 「音声保存」ボタンを押すと、**最前面にある対応ソフト**の選択中セリフを自動で書き出し
- 書き出し先の指定、ファイル名の入力、ダイアログの操作はすべてプラグインが代行
- 保存対象のソフト名はボタンに常時表示(例: 音声保存（CeVIO AI）)
- 保存の成功/失敗はボタンの色(緑/赤)とログで通知

### ⌨️ グローバルホットキーで保存

- 音声合成ソフトを前面にしたまま、ホットキー(既定: `Ctrl+Alt+S`)で保存を実行
- ウィンドウを切り替えず、セリフ入力から手を離さずに保存できる
- キーの組み合わせは「キーで設定」で実際にキーを押して登録可能

### 📁 ファイル名と保存先の自動整理

- ファイル名は `タイムスタンプ_キャラクター名_セリフ先頭10文字.wav` で統一
- セリフ全文を記録した同名の txt(UTF-8 BOM 付き)を自動で併設
- 「キャラクター毎にフォルダを分けて保存」オプションあり
- 姉妹プラグイン **Voice Drop** の監視フォルダに保存先を連動させるオプションあり
  (保存 → タイムラインへ自動配置までがつながる)

### 🗂 プロファイル(作品ごとの環境切り替え)

- 「保存先 + 保存オプション + 起動するソフト(+開くプロジェクト)」をセットで保存
- プロファイルを適用すると、保存先を切り替えつつ**未起動のソフトを自動起動**
- 「現在の状態をプロファイルとして保存」で、起動中ソフトと設定をそのままキャプチャ
  (名前は AviUtl2 のプロジェクト名から自動取得)
- ドラッグで並び替え、複製・編集・削除に対応

### 🖥 起動中ソフトの確認

- 対応ソフトの一覧をヘッダーからいつでも確認
- 起動中は緑・未起動はグレーで表示し、起動中のソフトが上に並ぶ
