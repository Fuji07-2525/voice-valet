# Voice Valet

音声合成ソフトの「音声保存」を代わりにやってくれる、AviUtl2 用のプラグインです。
書き出しのメニュー操作、保存先の指定、ファイル名の入力をすべて自動で行うので、
ボタン1つ（またはショートカットキー1つ）で、セリフの音声を決まった場所に、決まった名前で保存できます。

## 動作環境

- AviUtl2 2.1.11 以上
- Windows 10 / 11（64bit）

## インストール

1. [Releases](https://github.com/Tksn07/aviutl2-voice-valet/releases) から最新の `voice_valet.aux2` をダウンロード
2. AviUtl2 の Plugin フォルダ（例: `C:\ProgramData\aviutl2\Plugin`）に入れる
3. AviUtl2 を起動し直す

## 主な機能

### 🎙 ボタン1つで音声保存

- 「音声保存」ボタンを押すと、いちばん手前に表示されている音声合成ソフトの、選択中のセリフを保存します
- 保存先の指定、ファイル名の入力、ダイアログの操作は、すべて Voice Valet が代わりに行います
- どのソフトが保存されるかは、ボタンに表示されます（例: 音声保存（CeVIO AI））
- 保存の結果はボタンの色でわかります（成功は緑、失敗は赤）。詳しい内容は画面のログで確認できます

### ⌨️ ショートカットキーで保存・再生

- 音声合成ソフトを使いながら、キー1つで保存・再生できます。ソフトの画面から手を離す必要はありません
  - 音声保存: `Ctrl + Shift + R`
  - 音声再生: `Ctrl + Shift + Space`
- ショートカットキーが効くのは、対応している音声合成ソフトを使っている間だけです。ブラウザなど他のアプリでは、同じキーがいつもどおり使えます
- 音声合成ソフト自身に同じキーの機能がある場合は、Voice Valet の操作が優先されます
- キーは「設定」画面で好きな組み合わせに変えられます。「設定」ボタンを押して、使いたいキーを実際に押すだけです（↺ で元に戻せます）
- 他のアプリが同じキーを使っていて登録できないときは、設定画面にその旨が表示されます

### 📁 ファイル名と保存先をきれいに整理

- ファイル名は `日時_キャラクター名_セリフの先頭10文字.wav` の形にそろいます
  （例: `20260821213000_結月ゆかり_みなさんどうも初めま.wav`）
- ソフトごとに「この名前にそろえる」か「ソフトの元の名前のまま保存する」かを選べます（初期設定はすべて「そろえる」）
- 同じ名前のファイルがすでにあるときは、`_2`、`_3` … を付けて保存します。上書きで消えることはありません
- セリフのテキストファイル（txt）は、各ソフトの設定で「テキストも書き出す」にしていれば、音声と同じ名前で一緒に保存されます（VoiSona Talk は Voice Valet が自動で作ります）
- 「キャラクターごとにフォルダを分けて保存」もできます。「紲星あかり」「あかり テンションアップ」のように名前が少し違うものも、登録した名前（例: あかり）の1つのフォルダにまとめられます（主要キャラクター111名は最初から登録済み）
- 姉妹プラグイン **Voice Drop** と組み合わせると、保存した音声が AviUtl2 のタイムラインに自動で並びます（保存先を Voice Drop の監視フォルダに合わせる設定があります）

### 🗂 プリセット（作品ごとの作業環境をまとめて切り替え）

- 「保存先」「起動する音声合成ソフト（と、開くプロジェクト）」「AviUtl2 のプロジェクト」をセットで登録できます
- プリセットを選んで適用すると、保存先が切り替わり、まだ起動していないソフトが自動で起動します（プロジェクトを指定していれば、それを開いた状態で起動します）
- 「このプロジェクトを開いたときにプリセットを適用する」をオンにすると、AviUtl2 でそのプロジェクトを開いたときに確認が出て、ワンクリックで作業環境がそろいます
- 「現在の状態をプリセットとして保存」を押すと、いま起動しているソフト、それぞれが開いているプロジェクト、現在の保存先をまとめて登録できます（名前は AviUtl2 のプロジェクト名から自動で付きます）
- ドラッグで並び替えられます。複製・編集・削除もできます
- ※ プリセットを適用しても、AviUtl2 のプロジェクトは開きません（AviUtl2 側で開いてください）

### 🔗 Voice Drop のルールを自動で作成

- 「VoiceDrop」タブで、起動中の音声合成ソフトからキャラクターの一覧を読み込み、Voice Drop 用のルールをまとめて作れます
- 作ったルールはファイルに書き出して、Voice Drop に読み込ませるだけで使えます。Voice Drop で自分で作ったルールは消えずに残ります

### 🖥 起動中のソフトを確認

- 画面左上の「● 起動中ソフト」から、対応ソフトの一覧をいつでも確認できます
- 起動中のソフトは緑、起動していないソフトはグレーで表示され、起動中のソフトが上に並びます

## 対応ソフト

| ソフト | 音声保存 | 音声再生 | キャラクター読み込み（VoiceDrop タブ） |
|---|:---:|:---:|:---:|
| VOICEROID2 Editor | ✅ | ✅ | ✅ |
| A.I.VOICE Editor | ✅ | ✅ | − |
| A.I.VOICE2 Editor | ✅ | ✅ | ✅ |
| VOICEPEAK | ✅ | ✅ | ✅ |
| VoiSona Talk Editor | ✅ | ✅ | ✅ |
| CeVIO AI | ✅ | ✅ | ✅ |
| CeVIO CS（Creative Studio） | ✅ | ✅ | ✅ |
| VOICEVOX | ✅ | ✅ | ✅ |
| COEIROINK v2 | ✅ | ✅ | ✅ |

## 使う前に確認してほしい、ソフト側の設定

一部のソフトは、次の設定にしておく必要があります。設定が合っていないときは、保存時に Voice Valet が案内を表示します。

| ソフト | 必要な設定 |
|---|---|
| A.I.VOICE Editor | 「ツール > 環境設定」の「音声保存時に毎回設定を表示する」をオン |
| VOICEVOX | 設定の「書き出し先を固定」をオフ |
| COEIROINK v2 | 設定の「書き出し先を固定」をオフ |
| VOICEPEAK | 「環境設定 > キー」で、ブロックの出力と再生にキーが割り当てられていること（初期設定のままなら何もしなくて大丈夫です） |

上の表にないソフトは、特に設定しなくても使えます。

## ご注意

- Voice Valet は、音声合成ソフトの画面を自動で操作して保存します。ソフトのアップデートで画面の作りが変わると、うまく動かなくなることがあります
- 保存が終わるまで（ボタンが「音声保存中」の間）は、音声合成ソフトの画面を触らずにお待ちください
